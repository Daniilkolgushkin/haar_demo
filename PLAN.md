# План реализации Haar Audio Lab

Обновлён по указанию пользователя: C++20 + Emscripten вместо Rust; long-work-resume не используется.

1. Удалить локальные Rust SDK/исходники, обновить спецификацию и сборочные зависимости.
2. Реализовать независимое C++ ядро полного DWT/IDWT, symmetric padding, компактные маски, stereo и peak guard. Проверить native тестами и независимым Python-эталоном.
3. Собрать ядро в WASM через Emscripten. C ABI + TypeScript glue с явным владением памятью; вычисления только в Worker.
4. Завершить Canvas UI, zoom/pan, маски, загрузку и Web Audio. Защитить загрузку/рендер/реконструкцию от устаревших запросов.
5. Проверить unit tests, typecheck, production build, Chromium smoke под / и /repo/. Добавить GitHub Pages workflow и README с результатами и ограничениями.

Готовность: реальная загрузка WAV → полное DWT в WASM → оранжевая маска → IDWT → playback → reset; автоматические проверки проходят, dist содержит WASM, публикация настроена. Сам деплой требует GitHub-репозитория и не считается проверенным локальной сборкой.

## Результат

Этапы 1–5 выполнены. C++ native/эталонные тесты, JS tests, typecheck, production build и Chromium smoke под / и /repo/ проходят. README содержит команды, архитектуру, ограничения и перечень проверок. Реальная публикация и Firefox не выполнялись; это ограничения проверки окружения, а не завершённый deploy.
